Eine AMU-Anwendung sicher verbinden
  1. Als Administrator unter „Anwendungen“ einen eigenen Namen anlegen. Für Chat genügt die Rolle Inferenz mit Modell- und Chat-Freigabe.
  2. Den einmaligen Schlüssel geschützt in der Anwendung speichern. Über „Verbindungskonfiguration“ das zugehörige Profil aufrufen.
  3. Auf diesem Computer funktioniert die lokale Adresse. Auf einem zweiten Computer eine private HTTPS-IP oder Domain mit passendem Zertifikat und öffentlicher CA verwenden.
  4. Für LAN zuerst Zertifikat, Bind-Adresse und erlaubtes Subnetz prüfen. Firewall-Freigaben separat genehmigen lassen. Den Schlüssel niemals in eine URL schreiben.
  5. Vom Client zuerst Modelle auflisten, dann eine kurze Antwort und Streaming prüfen. Ein lokaler Test bestätigt keine Verbindung zweier Computer.

Gesicherte Backups herunterladen und auf einem getrennten Medium speichern. Passwort/Wiederherstellungsschlüssel getrennt aufbewahren. Ein manueller Programm-Rollback erfolgt nur bei gestopptem Dienst nach der Betriebsanleitung; aktuelle Datenbanken und Zugänge bleiben erhalten.
